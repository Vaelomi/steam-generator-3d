# CAP1000 / CAP1400 蒸汽发生器三维结构图谱

参照相邻「CAP1400反应堆压力容器三维爆炸图」项目的三栏界面、双主题和离线运行方式，为蒸汽发生器独立建立的交互式三维模型。

双击 `index.html` 或 `启动蒸汽发生器.bat` 即可打开，运行不需要网络、安装依赖或构建。请保留 `assets/` 和 `lib/` 文件夹。需要支持 WebGL 的现代浏览器。

这是结构展示示意，不是制造图、施工图或安装规程。焊接件分离仅帮助识别结构关系。

## 已实现

- CAP1400 / CAP1000 独立配置切换：同步改变几何包络、抽样管束、分离器显示阵列、设备参数和资料说明。
- 默认以完整总装打开；总装视图只显示承压边界与外部附件，内部件在剖视、分解或局部检视中显示；可切换总装、爆炸、剖视，并以 0–100% 连续分解或循环播放动画。
- 37 个结构组，包含上、下筒体及封头、管板、水室、U 形管束、管束保持环和保持条、套筒支撑销钉、初级分离器、干燥器、给水环和肘管、主蒸汽出口文丘里、水室隔板短筋、两只泵壳及 MIMS 传感器安装块等。
- 爆炸图按管束—水室、下筒体 C 段—锥体、上筒体—分离器、干燥器、上封头五组展示；焊接件的分离仅供识别。
- 四种常用局部检视和爆炸图中的五个结构分组；支持单独查看任意部件。
- 剖开外壳包含内外表面和材料截面；管板及支撑板的抽样孔位对应 U 形管腿。
- 一次侧管内、二次侧管外流路示意：启动时自动回到总装剖视，动画不具有热工计算含义。
- 点击三维实体、标签、组成示意图或目录查看部件；搜索、显隐、聚焦、恢复全部。
- 默认夜间外观，支持白天 / 夜间 / 跟随系统切换并记住选择；支持功能分区 / 工业银灰模型配色、线框、引线、自动旋转。
- 正视、侧视、俯视、全屏；导出带标注的 PNG 和包含来源的参数 JSON。
- 自适应窄屏布局；所有三维库、图标、脚本均本地提供。
- 静止画面停止连续绘制；重复管腿、弯管和分离器使用实例化几何。

## 交互

| 操作 | 作用 |
|---|---|
| 左键拖动 / 单指拖动 | 旋转 |
| 滚轮 / 双指手势 | 缩放 |
| 右键拖动 | 平移 |
| 点击部件 | 选择并查看档案 |
| `R` | 重置当前可见结构的视角 |
| `P` | 播放 / 暂停分解动画 |
| `/` | 打开目录并搜索 |
| `Esc` | 退出局部检视或取消选择 |

顶部书本按钮打开资料说明。右侧型号对比可切换设备，并导出全部配置及资料依据。

## 参数口径

| 参数 | CAP1000 配置采用的 AP1000 参考 | CAP1400 公开设计基线 |
|---|---:|---:|
| 传热管数 | 10,025 | 12,606 |
| 传热面积，m² | 11,477 | 14,666 |
| 管外径，mm | 17.48 | 17.48 |
| 表列长度，m | 壳体总长 22.45 | 总高 24.00 |
| 上筒体内径，m | 5.330 | 6.120 |
| 下筒体内径，m | 4.190 | 4.655 |
| 一次侧进口 / 出口 | 1 / 2 | 1 / 2 |

CAP1400 主参数来自 SNPTC 2015 设计介绍；CAP1000 暂使用西屋 AP1000 公开设计基线作为体系参考，**不是 CAP1000 实机已核参数**。两个资料的长度定义也不同，不可直接当作相同测量口径。

传热管抽样显示：CAP1400 为 106 根，CAP1000 为 81 根。显示管径为 70 mm，便于辨认，实际外径 17.48 mm 另列于参数卡。管束配色用于功能识别，不表达实物的金色材料。

参考用户提供的 HY5 日报“设备周报”和 HY6 制造计划任务文本补充了部件名称及制造分组。计划不是零件图；新增零件的外形、尺寸、方位和连接细节均为示意。七个主蒸汽出口限流文丘里来自 AP1000 公开资料，CAP1400 数量待核。余排管嘴按海阳6号 A 型计划示意，不能视为全部设备的通用配置；CVS 等仅在部分水室计划中出现的接口未推定为通用件。

除明确列为公开值的项目外，模型中的壳体厚度、分段高度、孔位、接管尺寸和方位、板层数、分离器台数、支承形式及材料牌号均待制造图核准。不会从屏幕抽样数推定实机数量。

详细资料索引与建模边界见 [资料与建模说明](docs/资料与建模说明.md)。

## 本地服务预览（可选）

直接双击即可使用。需要 HTTP 预览时，在本目录运行：

```powershell
python -m http.server 8972 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8972/`。静态部署时使用整个目录，`index.html` 为首页，无需构建步骤。

## 后续按实机图纸细化

设备图纸或参数表到位后，优先修改 `lib/profiles.js`：`public` 保存有依据的参数，`geometry` 保存显示几何，`parts` 保存部件说明。复杂零件的建模在 `lib/model.js` 中调整。

目前没有把 AP1000 参考配置或 CAP1400 概念设计资料当作竣工制造基线。
