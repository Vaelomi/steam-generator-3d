## 3. 结构表达

| 结构 | 当前表达 | 边界 |
|---|---|---|
| 上下筒体 | 内径按型号独立配置，空心回转壳体 | 厚度和分段标高为示意 |
| 过渡段 / 封头 | 空心回转体、材料截面、主蒸汽贯通口 | 曲线、壁厚分布、开孔细部待核 |
| U 形管束 | 两个直管腿及半圆弯管；与孔位对应 | 仅抽样，不逐根绘制真实管数 |
| 管板 | 闭合实体板、贯通抽样孔、外缘环带 | CAP1400 厚度及孔距为示意 |
| 支撑板 | 与管束对应的抽样孔阵列 | 8 层是显示选择，不代表实机层数 |
| 防振组件 | 弯管区的条带形态 | 真实数量、接触和间隙待核 |
| 套筒 | 空心剖开导流筒、下部回流空间 | 套筒及支撑结构待核 |
| 初级分离器 | 立式管状阵列与简化叶片 | CAP1400 显示 29 个、CAP1000 显示 21 个，均非实机已核台数 |
| 干燥器 | 支承环、框架与波形板片示意 | 板型、数量和流道尺寸待核 |
| 主蒸汽限流构件 | 出口接口处七根文丘里和对应孔口 | 数量按 AP1000 参考，CAP1400 数量、孔形和尺寸待核 |
| 保持件 / 套筒支撑销钉 | 管束外侧保持环、保持条和下筒体支撑销钉 | 数量、接触与连接方式均为示意 |
| 给水肘管 / 上部支承 | 给水环连接件、外接盘及下部支撑环 | 走向、标高和结构细节待核 |
| 一次侧水室 | 分为两腔的下封头、隔板短筋、MIMS 安装块、一个进口、两个出口和两只泵壳 | 准确内表面、附件位置、泵壳外形与补强待核 |
| 余排管嘴 | 按海阳6号 A 型水室计划示意 | 其他水室和 CAP1400 的适用性待核；CVS 未作为通用部件绘制 |
| 给水 / 排污 / 检修口 / 支承 | 功能识别用接口 | 数量、位置、尺寸与材料按项目图纸确认 |

单位采用米，Y 为设备轴线。公开长度按显示包络拟合；三维坐标不是制造标高。封头或壳体剖开包含材料端面，截面配色用于视觉识别。

总装视图只显示承压边界、外部接管与附件，内部件（管束、支撑板、保持件、防振组件、套筒、分离器、干燥器、给水环与肘管、水室隔板与短筋、限流文丘里）默认隐藏，避免从敞开的接管或人孔看进壳体内部而把内部结构误读为外表面缺陷。切换到剖视、分解或局部检视时内部件恢复显示；在总装视图中点击目录里的内部件会自动切换到剖视再聚焦。

## 4. 抽样规则

CAP1400 抽样显示 106 根 U 形管，CAP1000 显示 81 根。每根管两条直管腿，管板和支撑板的孔按相同坐标生成。

显示管外径取 70 mm，实际外径 17.48 mm 另列于参数与部件说明。支撑板显示孔径略大于管径以避免视觉交叠；不据此推定实际制造间隙。

金色代表换热组件，青绿色代表汽水分离，蓝色代表接管，银灰代表承压壳体。功能配色不表达实际材料颜色；可切换工业银灰。

## 5. 分解与流路

焊接件在爆炸视图中的分离只帮助阅读组成关系，不表示实际拆装步骤。管束、管板、保持件、水室及泵壳保持同组；下筒体 C 段、锥体和套筒支撑销钉同组侧移；上筒体、分离器及给水环同组；干燥器和上封头沿轴向分层。管腿和孔保持相对对应。

流路功能自动返回总装剖视：一次侧沿管内上行、越过 U 弯并下行，经出口连接主泵；二次侧经给水、下降通道、管束换热区、汽水分离和干燥后由主蒸汽出口离开。箭头和粒子速度仅表示方向，不表示流量、温度、压力或运行边界。
